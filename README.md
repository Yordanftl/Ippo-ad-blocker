# Ippo AdBlocker

A Manifest V3 ad blocker for Chrome, Brave, Opera, and Safari.

**v1.0.0** — initial release. Network-level blocking of 3,568 known ad/tracker
domains (Peter Lowe's list) plus basic cosmetic filtering.

> Looking for the current version? See `main` — v2 blocks 190k+ rules,
> YouTube video ads, and popups.

## Install (Chrome / Brave / Opera)

1. Download `ippo-adblocker-v1.0.0.zip` from Releases and unzip it.
2. Open `<browser>://extensions`, enable **Developer mode**.
3. **Load unpacked** → select the unzipped `extension/` folder.
